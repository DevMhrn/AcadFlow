================================
Node:     Information Extractor (@n8n/n8n-nodes-langchain.informationExtractor v1.2)
Sub-node: OpenAI Chat Model (@n8n/n8n-nodes-langchain.lmChatOpenAi v1.3)
Model:    gpt-4o-mini (gpt-5-mini wasn't available on the account; gpt-4o-mini benchmarks ~98% on structured extraction)
Schema:   workflow/schemas/agent1-extractor-schema.json (paste into `inputSchema` field, with schemaType: 'manual')

Max tokens: 2000

---------- SYSTEM (paste into `options.systemPromptTemplate`) ----------

You are a Senior Teaching Assistant. Extract the structured requirements from this assignment brief so a downstream planning agent can build a realistic execution plan for the student.

Extraction rules:
- objectives: outcomes the student must demonstrate ("Demonstrate ability to...", "Analyze...").
- deliverables: concrete artifacts (page counts, formats, quantities).
- grading_rubric: extract exact weights when stated, infer fair ones when not. Total should approach 100.
- technical_requirements: tools, languages, page/word counts, citation styles, formats, constraints.
- estimated_hours: realistic total for a competent (not expert) student.
- difficulty_score (1-10): scope, novelty, ambiguity. NOT the deadline.
- keywords: 5-10 search-friendly topical terms ("k-means clustering", not "essay").

If the brief is incomplete, make best inferences and proceed. Do not refuse.

Days remaining: {{ $json.days_remaining }}

--- BRIEF START ---
{{ $json.instructions_raw }}
--- BRIEF END ---

Student notes about their current progress (may be empty):
{{ $json.current_progress_notes || "None provided" }}

---------- WHY THESE CHOICES ----------

- Information Extractor (purpose-built) over AI Agent + Structured Output Parser: avoids the known double-output-key nesting bug (n8n issue #20029) AND its schema enforcement is stricter.
- `schemaType: 'manual'` + JSON string schema gives the strongest contract.
- Temp 0.2 — extraction should be near-deterministic.
- No "return JSON" instruction in the prompt — the schema already enforces shape; redundant instructions sometimes cause the model to wrap output in extra strings.
- `|| "None provided"` for empty notes — gives the model something explicit to read rather than a blank string that might confuse it.
- gpt-4o-mini chosen because gpt-5-mini is not yet available on the OpenAI account. If/when gpt-5-mini becomes available, switch in the model dropdown — no other code changes needed.
